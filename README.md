# Installation
1. Create a virtual environment
```powershell
python -m venv .venv
```
2. Run the following command to install everything in the requirements.txt file
```powershell
pip install -r requirements.txt
```
3. Use the command ```python3 5x5.py``` to run the game
4. Enjoy..?
